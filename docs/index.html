Je beleggingen in één oogopslag

Deze site toont je Trading 212-portefeuille, opgehaald door je eigen Cloudflare Worker. Je hebt alleen een gratis Cloudflare-account en een Trading 212 API-sleutel nodig; extra functies zet je later aan met gratis sleutels.

Zo zet je je eigen tracker op. Heb je hem al? Vul dan het adres van je Worker en je toegangscode in.

Adres van je Worker

Het adres van je Cloudflare Worker, eindigend op /api/data (bijvoorbeeld https://investment-tracker.jouwnaam.workers.dev/api/data). De oude Apps Script-web-app (eindigt op /exec) werkt ook. Leeg laten: het standaardadres van deze site.
